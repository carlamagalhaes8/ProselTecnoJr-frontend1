# Landing Page — Dona Marta

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page para o negócio de Dona Marta, com o objetivo de apresentar o estabelecimento, destacar seus produtos e facilitar o contato dos clientes para a realização de encomendas.

O desenvolvimento foi baseado nas informações obtidas durante a entrevista com a proprietária, considerando principalmente a identidade visual do negócio, o uso de cores terrosas e a sensação acolhedora que a página deveria transmitir aos visitantes.

A proposta é oferecer uma experiência simples, agradável e intuitiva, permitindo que os clientes encontrem facilmente as informações sobre o estabelecimento e conheçam seus principais produtos.

## Objetivos

- Representar a identidade visual do negócio por meio de um design acolhedor;
- Apresentar os principais produtos de forma organizada e atrativa;
- Disponibilizar informações importantes sobre o estabelecimento;
- Facilitar o acesso aos horários de funcionamento e endereço;
- Incentivar o contato dos clientes para realização de encomendas.

## Tecnologias utilizadas

- **HTML:** estruturação dos elementos da página;
- **CSS:** estilização, cores, layout e responsividade;
- **JavaScript:** implementação de funcionalidades e interatividade;
- **React:** desenvolvimento da interface por meio de componentes;
- **VS Code:** ambiente de desenvolvimento;
- **Git e GitHub:** versionamento e armazenamento do projeto.

## Ferramentas de apoio

Durante o desenvolvimento, foram utilizadas ferramentas de inteligência artificial para auxiliar na criação do design, agilizar a implementação do CSS e esclarecer dúvidas relacionadas à programação.

## Funcionalidades

- Apresentação do negócio;
- Exibição dos principais produtos;
- Informações sobre o estabelecimento;
- Seção de horários e endereço;
- Layout com identidade visual baseada em cores terrosas;
- Interface intuitiva e responsiva;
- Acesso facilitado ao contato para encomendas.

## Como executar o projeto

### Pré-requisitos

- Node.js;
- npm.

### Instalação

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd NOME_DO_PROJETO
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Acesse no navegador:

```text
http://localhost:5174
```

## Desenvolvimento

Durante o desenvolvimento, foram realizados testes e ajustes na interface para garantir uma apresentação organizada e coerente com a identidade visual do negócio.

Algumas dificuldades estiveram relacionadas à retomada de conceitos de programação e estilização que não eram utilizados há algum tempo. Essas dificuldades foram superadas por meio de consultas, testes e utilização de ferramentas de apoio, contribuindo para o reforço dos conhecimentos e para o desenvolvimento do projeto.

## Autoria

Projeto desenvolvido como parte de uma atividade acadêmica, a partir das informações obtidas em entrevista com Dona Marta.
